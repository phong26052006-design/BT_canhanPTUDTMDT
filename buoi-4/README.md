## Game Trảm Long được tạo với Codex

[HTML hoàn chỉnh, một tệp](game-tram-long/tram-long-hoan-chinh.html)

Tải tệp HTML, mở bằng Chrome hoặc Edge. Chọn phân cấp, bật âm thanh nếu muốn rồi bắt đầu trận chiến. Có hoạt ảnh kiếm chém, hỏa cầu, né đòn, bị thương, chí mạng, thanh máu, nhật ký, tạm dừng và tốc độ. CSS, JavaScript, SVG và âm thanh Web Audio đều nằm trong tệp; không cần thư viện hay Internet. Font Segoe UI/Tahoma/Arial hỗ trợ tiếng Việt.

## Phân biệt hai bản

Đây là hai bản riêng, không ghi đè bản của sinh viên. Bản gốc hiện tại cộng 300 XP khi lên cấp 3 và xét chí mạng bằng random < intel; bản Trảm Long kế thừa bản xử lý đã cung cấp đầu cuộc trao đổi: cộng 200 XP ở bước đó và xét random > intel. Cả hai đều có tổng sát thương chí mạng bằng 3 lần sức mạnh. Không tự thay đổi quy tắc bản gốc để đồng nhất hai bản.

GitHub hiển thị mã nguồn HTML; tải về để chơi. Chưa cấu hình GitHub Pages cho thư mục này.
